✅ Expected Behavior:
• Extension scans page content every 5 seconds
• When a key is detected, a Chrome notification appears
• Notification shows: "KeyShield: API Key Detected!"

• Same key won't trigger duplicate notifications (deduplication)
🐛 Debugging:
• Open Chrome DevTools (F12) → Console tab to see detection logs
• Check chrome://extensions → KeyShield → "Inspect views: service worker" for background logs
• Verify extension has "notifications" permission enabled
