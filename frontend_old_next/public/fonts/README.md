# Font Files Directory

This directory should contain the font files from the `keyshield_font` repository.

## Expected Font Files

Please add the following font files to this directory:
- Font files in formats: `.woff2`, `.woff`, `.ttf`, or `.otf`
- Multiple weights if available (e.g., `keyshield-regular.woff2`, `keyshield-bold.woff2`)

## Font Family Name

The font family name used in the CSS is `'KeyShield'`. If your font has a different name, update the `font-family` property in `globals.css`.

## After Adding Fonts

Once font files are added, the application will automatically use them. The font is configured to replace both Inter and JetBrains Mono fonts throughout the application.
