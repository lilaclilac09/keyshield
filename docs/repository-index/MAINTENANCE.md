# Maintenance

Future **code changes or original-file moves** require:

1. Explicit scope
2. A separate branch
3. Scoped commits
4. A pull request
5. Relevant regression tests
6. Real screenshots for UI changes
7. Index updates
8. Aileena’s approval
9. No automatic merge

This index task prepares a PR title and description only when asked.
Do not treat an index commit as approval to relocate source.
