The problem

You're building AI agents.
Here's what keeps breaking.

Keys leak.

You put OPENAI_API_KEY in .env. It shows up in logs, CI artifacts, crash dumps, ps aux. One leaked key costs $4,500 on average. It happens every day.

Agents can't pay.

Your agent calls OpenAI 10K times a day. Who pays? You pre-fund a credit card? OAuth assumes a human clicking "approve." Your agent isn't one. There's no native payment rail.

You lose control.

Once you hand a key to your agent, it has your full access forever. No spending cap. No scope limit. No kill switch. If the agent goes rogue, the key is already in the wild.

The solution

Don't give your agent the key.
Give it a wallet.

KeyShield is a proxy between your agent and every API it calls. Your keys are encrypted on your device and never leave. The proxy injects them per-request. Solana handles billing.

1

You store your keys once.

Encrypted on your device with your Solana wallet signature. AES-256-GCM. The server stores ciphertext it literally cannot read.

2

Your agent calls the proxy.

Same OpenAI / Anthropic / Helius SDK. Same code. The proxy decrypts the key in memory, forwards the request, throws the key away. Agent never sees it.

3

Solana settles the bill.

Your agent gets its own on-chain wallet with a spending cap you set. 10K API calls batch into one Solana transaction every 60 seconds. USDC. Transparent. Revocable.

Three lines. That's it.

from keyshield import KeyShield ks = KeyShield(token="ksv2_...") openai = ks.openai_client() # your key never touches agent memory resp = openai.chat.completions.create( model="gpt-4o", messages=[{"role": "user", "content": "hello"}] )

What makes us different

Not another secrets manager.
This is infrastructure.

iCloud Keychain grade

The server can't read your keys.

Your Solana wallet signature derives an AES-256-GCM key. Encryption happens in your browser. The server only stores ciphertext. Even if we get hacked, your keys are safe. Same security model as iCloud Keychain — but for API keys, built for agents.

on-chain USDC

Your agent has its own wallet.

You mint an Ephemeral Signer on Solana. Top it up with USDC. Set a spending cap the chain enforces. Your agent pays API providers directly — no credit card, no human approval, and it can't outspend the limit because the blockchain says no.

200× cheaper

10K calls. One transaction.

x402 charges per API call — too expensive for real agents. Our Metered Payment Protocol records calls off-chain at microsecond speed and settles once every 60 seconds on Solana. One batch. One fee. Streaming actually works.

50–80ms

Rust proxy. Helius accelerator.

The hot path is six Rust crates with two-tier caching. Solana RPC calls go through our HeliusClient with memory + disk cache and single-flight dedup — 50 identical calls fire upstream once. Your agent gets 30–80ms Solana reads.
