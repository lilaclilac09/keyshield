Ephemeral Signer

Give your agent its own wallet

On-chain pubkey minted by ix #23–#27. You top it up, set the cap, walk away. The agent signs x402 payments solo — and can't outspend the limit because the chain enforces it.

200× faster than per-call x402

MPP Streaming

$0.001/call. Settle once a minute, not every token.

One PaymentStream PDA per session. 10K inference calls record off-chain in microseconds, then collapse into a single on-chain settle every 60s. No 402 round-trip on the hot path.

78 oracle tests · byte-equal

Rust hot path

50–80ms median. AES-256-GCM decrypt every call.

Five crates — vault, session, cache, upstream, proxy. Each one byte-diffed against a Python oracle on every PR. Cold logic stays in Python; only the request path is rewritten.
