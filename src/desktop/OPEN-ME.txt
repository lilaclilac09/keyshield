KeyShield for Mac

Local synthetic test build — not signed with a Developer ID and not notarized; macOS Gatekeeper protections are left intact.

Mount KeyShield.dmg and copy KeyShield.app to /Applications using Finder.
For a zip, extract the archive for your Mac and copy KeyShield.app to /Applications.
Apple Silicon uses the arm64 zip; Intel uses the x64 zip.

macOS may refuse to launch this build. This package does not modify system
security settings or provide a launch override. Tester distribution requires
a Developer ID signed and notarized build.

If the app opens but shows an error screen, use its Copy diagnostics
button, or read the launch log at:
  ~/Library/Logs/KeyShield/keyshield-desktop.log
BUILD-INFO.txt next to this file records which build you installed.
