Cross-device sync
Your vault key is derived from your wallet signature, so the SAME wallet produces the SAME key on every browser. Sign in to KeyShield in another browser (same wallet) and compare these 8 hex chars — if they match, both browsers can decrypt the same vault.

Backup & restore
Export your encrypted vault to a JSON file. Decryption still requires your wallet, so the file is safe to put on a USB drive, iCloud Drive, or even a public Gist — without the wallet sig it's opaque ciphertext.
